## 🚀 Proyectos destacados

### ⚓ [Atraquen el barco](https://github.com/alejandrodavidmartino/Parenlanave)
Juego de fiesta por turnos para jugar con amigos desde un solo móvil: sale una pregunta con respuesta numérica y los jugadores suben la apuesta sin pasarse.
Hecho con **Django + HTMX + Tailwind**, con el motor del juego en Python puro y cubierto al 100 % por tests. Desplegado en Render.

### 🎓 [SafeUse](https://github.com/alejandrodavidmartino/SafeUse)
Trabajo de Fin de Grado desarrollado en equipo: frontend en **React + TypeScript + Vite** y API en **PHP**, con Docker.

### 🎟️ Invitaciones con QR *(privado)*
Genera invitaciones con código QR a partir de un Excel y controla el acceso al evento escaneándolas desde el móvil. **PHP + MySQL**.
