## 🚀 Proyectos destacados

### 🎲 [Atraquen el barco](https://github.com/alejandrodavidmartino/Parenlanave)
Juego de fiesta por turnos para jugar con amigos desde un solo móvil: sale una pregunta con respuesta numérica y los jugadores suben la apuesta sin pasarse.
Hecho con **Django + HTMX + Tailwind**, con el motor del juego en Python puro y cubierto al 100 % por tests. Ruff, pre-commit y despliegue en Render.

### 🎬 [Butaca](https://github.com/alejandrodavidmartino/butaca) · [ver web](https://butaca-roan.vercel.app)
Aplicación para decidir qué película ver en grupo: apuntáis pendientes, una ruleta elige y cada uno puntúa lo que ve. Una mascota con IA recomienda según vuestras notas y las plataformas que tenéis en casa.
**React + Node.js + Express + MongoDB**, API REST con JWT y roles, y recomendaciones con **Gemini** verificadas contra el catálogo de TMDB.

### 🎓 [SafeUse](https://github.com/alejandrodavidmartino/SafeUse) · [ver web](https://safeuse.onrender.com/)
Trabajo de Fin de Grado desarrollado en equipo: frontend en **React + TypeScript + Vite** y API en **PHP**, con Docker.

### ♟️ [Torneo de ajedrez](https://github.com/alejandrodavidmartino/torneo-ajedrez) *(en construcción)*
Gestor de torneos por sistema suizo para la Asociación Vecinal Lucero, como voluntario. Funciona sin conexión y es gratuito.

### 🎟️ Invitaciones con QR *(privado)*
Genera invitaciones con código QR a partir de un Excel y controla el acceso al evento escaneándolas desde el móvil. **PHP + MySQL**.
